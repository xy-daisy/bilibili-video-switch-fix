# B站视频切换修复脚本 (Tampermonkey)

![version](https://img.shields.io/badge/version-3.0-pink)

![platform](https://img.shields.io/badge/platform-Chrome%20%2F%20Tampermonkey-blue)

![license](https://img.shields.io/badge/license-MIT-green)

> 点推荐视频后，让整个页面跟着新视频一起刷新，不再出现"播放器换了、其他区块还停着旧视频"的 B 站前端 bug。

---

## 问题背景

在 B 站观看视频时点击右侧推荐视频，常出现这样的怪现象：

- ✅ 播放器已经正常播放你点的**新视频**；
- ❌ 但标题、UP 主、简介、评论区、相关推荐列表，却**卡在旧视频**不动。

这是 B 站前端 SPA（单页应用）在"同组件切换视频"时没把周边区块一起刷新的 bug。本脚本自动帮你整页重新加载，让所有区块对齐到新视频。

---

## 效果（页面顶部状态横幅）

脚本在页面顶部显示一个状态横幅，让你**不用按 F12** 也能确认它在工作：

| 横幅颜色  | 含义                       |
| ----- | ------------------------ |
| 🟢 绿色 | 脚本正在运行 ✓                 |
| 🟠 橙色 | 检测到视频切换，即将整页刷新           |
| 看不到横幅 | 脚本没注入，请检查油猴"允许运行用户脚本"总开关 |

示例文本：

```
🟢 B站切换修复 v3 运行中（看到此条即脚本已注入） BV: BV1xx… | 已启用
🟠 B站切换修复 v3 已触发刷新：detected BV change BV1xx… -> BV2yy…
```

## 工作原理

1. **拦截路由切换**：包裹 `history.pushState` / `history.replaceState`（B 站切换视频用的客户端路由 API）。
2. **轮询兜底**：每 500ms 检查一次 URL，覆盖任何未被拦截的切换方式。
3. **智能触发**：一旦检测到 `BV 号` 真正变化，就自动整页重新加载——等价于手动按 F5，但全自动、零操作。
4. **精准不误伤**：只有换了一个视频（BV 号不同）才触发；同一视频**切分 P（`?p=`）不刷新**，追剧/看多 P 视频时体验平滑。

> 纯前端、无任何网络请求、无外部依赖。源码为纯 ASCII，中文在运行时解码。

## 安装

1. 安装油猴扩展 **Tampermonkey**（Chrome 应用商店搜索即可）。
2. 安装脚本：浏览器打开 `http://localhost:8753/bilibili-video-switch-fix.user.js`，油猴弹窗点"安装"；  
   或把 `bilibili-video-switch-fix.user.js` 文件直接拖进 Chrome 窗口安装。
3. **关键**：在 Tampermonkey 设置里打开 **"允许运行用户脚本"** 总开关——否则脚本虽显示"已启用"也不会注入页面（这是 Chrome MV3 的全局闸门）。
4. 重新打开一个 B站视频页，看到**顶部绿色横幅**即成功。

> ⚠️ 若 `localhost:8753` 打不开（临时服务器已关闭），直接用第 2 步的"拖文件安装"方式，不依赖服务器。

## 使用与验证

- 打开任意 B站视频页 → 顶部出现**绿色横幅**，脚本已生效。
- 点击右侧**推荐视频** → 横幅变**橙色**「已触发刷新」→ 页面自动重载 → 标题 / UP主 / 评论 / 推荐列表全部更新为新视频。

## 常见问题

| 现象              | 原因 / 处理                                           |
| --------------- | ------------------------------------------------- |
| 完全看不到横幅         | 油猴"允许运行用户脚本"总开关未开，或脚本未真正安装。先开开关，再重开页面。            |
| 横幅在但切换不刷新       | 极少见。按 F12 看 Console 里 `[BiliFix3]` 开头的日志，把内容反馈给我。 |
| 刷新后黑屏/重新缓冲约 1 秒 | 正常代价——等价于手动 F5，是绕开 B 站前端 bug 的必要开销。               |
| 同一视频切分 P 也被刷新   | 不会。脚本只在 BV 号变化时触发，分 P 不动。                         |

## 技术信息

- **匹配域名**：`bilibili.com` / `*.bilibili.com`（含裸域、www、m 及所有子域）。
- **运行时机**：`document-start`，页面加载即生效。
- **注入方式**：包裹 `History.prototype` 与实例的 `pushState` / `replaceState` + 轮询兜底。
- **更新**：已配置 `@updateURL`，油猴"检查更新"可拉取新版。
- **权限**：`@grant none`，不请求任何额外权限。
